## intentLM

intentLM (intentlm.ai) — We use intentLM to classify user session intent in real time. This enables us to personalise support responses and surface contextual offers based on your current interaction pattern. Data transmitted consists of pseudonymised tokenised event sequences (integer codes only). No raw page content, URLs, or personal information is transmitted.

Tokenised sequences are retained for 90 days and deleted thereafter.

Aggregated session data may be used to improve intentLM's intent classification models. Individual sequences are not shared with other customers.

For more information see https://intentlm.ai/privacy.
